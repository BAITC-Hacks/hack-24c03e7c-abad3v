# Инструкции для Codex

## Контекст

- Формат: хакатон по агентному ИИ.
- Направление: образование.
- Конкретный кейс: пока не объявлен. Актуальные условия записываются в `docs/CASE.md`.
- Стек, ограничения, критерии оценки и роли команды: пока не определены.

## Перед началом задачи

1. Прочитай `docs/CASE.md`, `README.md` и существующий код.
2. Отделяй подтверждённые требования от предположений. Не выдавай придуманную функцию за требование хакатона.
3. Когда кейс объявят, сначала обнови `docs/CASE.md`: точную формулировку, ограничения и критерии оценки. Затем предложи короткий MVP с демонстрируемым сценарием и приступай к реализации.
4. При выборе стека учитывай уже существующий проект и время до сдачи. Не добавляй сервисы и зависимости без нужды.

## Принципы реализации

- Делай работающий сквозной сценарий: ввод пользователя → действия агента → проверяемый результат.
- Явно показывай, какие шаги агент делает сам, какими инструментами пользуется и где требуется подтверждение человека. Не называй обычный чат агентом без соответствующего поведения.
- Отмечай в интерфейсе и документации, что работает на реальных данных, а что является демонстрационным примером.
- Для образовательных ответов давай объяснение и источник, если источники доступны; неопределённость показывай явно. Не представляй сгенерированный ответ как проверенный факт.
- Собирай минимум персональных данных учащихся. Секреты храни только в переменных окружения; реальные ключи, токены и личные данные не коммить.
- Делай небольшие понятные изменения и сохраняй возможность запустить демонстрацию даже при недоступности внешнего ИИ-сервиса, если это допускает кейс.

## Проверка и передача результата

- После изменений запускай доступные команды проверки проекта. Если команды ещё не определены, не придумывай, что тесты прошли.
- В ответе кратко укажи, что изменено, как это запустить или проверить и какие ограничения остались.
- Обновляй `README.md` при изменении запуска и `docs/CASE.md` при уточнении условий.

## Команды проекта

- Установка зависимостей: `npm.cmd install` из корня.
- Запуск: `npm.cmd run dev` (API и Vite); после сборки — `npm.cmd start`.
- Проверка: `npm.cmd test`.
- Сборка: `npm.cmd run build`.

Начальное демонстрационное наполнение: `npm.cmd run seed`. Нужен Node.js 24.x с `node:sqlite`.
