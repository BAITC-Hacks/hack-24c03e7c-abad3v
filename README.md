# AI Sana — hackathon MVP

Рабочий репозиторий команды AbaD3v. Backend реализован в `server/`; frontend Нурдаулета подключается по контракту [shared/CONTRACT.md](shared/CONTRACT.md). Полный продуктовый план — [HACKATHON_PLAN.md](HACKATHON_PLAN.md).

## Быстрый запуск backend

Нужен Node.js 24.14.0 или совместимая 24.x с `node:sqlite`.

```powershell
cd server
npm.cmd install --offline=false
Copy-Item .env.example .env
npm.cmd run seed
npm.cmd run dev
```

API будет доступен на `http://localhost:3001/api`. Проверка: открыть `http://localhost:3001/api/health`; ожидается `{"status":"ok","db":"ok"}`. `npm.cmd run seed` можно повторять: пять задач, пять команд и пять предложений добавляются только один раз. Демо-профили создаются при первом старте сервера. При запуске без seed каталог первоначально пуст.

Для frontend в Vite настройте proxy `/api` → `http://localhost:3001`. Browser fetch должен отправлять cookie (`credentials: "include"`). Сначала запросите `GET /api/demo/actors` и выберите профиль через `POST /api/demo/session`. Далее можно создавать задачи и отклики.

В PowerShell пример получения сессии и создания черновика:

```powershell
$api = 'http://localhost:3001/api'
$session = Invoke-RestMethod "$api/demo/session" -Method Post -ContentType 'application/json' -Body '{"actorId":"business-demo"}' -SessionVariable demo
$task = Invoke-RestMethod "$api/tasks" -Method Post -ContentType 'application/json' -WebSession $demo -Body '{"draftText":"Нужно приложение для студентов","topic":"education"}'
$task.task.id
```

## AI

По умолчанию `AI_MODE=auto`. Если в `server/.env` нет `OPENAI_API_KEY`, `/api/tasks/:id/analyze` возвращает `mode:"template"` и вопросы по правилам; весь путь до выбора команды работает. Чтобы проверить живую генерацию, добавьте серверный `OPENAI_API_KEY` в `server/.env`. Ключ нельзя передавать во frontend или сохранять в git. Допустимые значения `OPENAI_MODEL`: `gpt-6-sol` (по умолчанию) и `gpt-6-luna`. Доступ модели и баланс аккаунта нужно проверить в аккаунте команды; здесь платные вызовы не выполнялись.

Сервер ограничивает размер входа, количество вопросов и вызовов, резервирует верхнюю оценку стоимости, записывает usage в SQLite и переходит на шаблон при сбое AI. `AI_MODE=template` принудительно включает локальный режим для репетиции. `AI_BUDGET_CAP_USD=15` — предел расходов этого приложения на этапе разработки; для использования зарезервированного демо-бюджета его можно поднять после проверки остатка на аккаунте. Оценка бюджета и детали — в плане.

## Правила продукта

- Карточка создаётся из свободного текста, затем пользователь отвечает на вопросы и сам подтверждает отредактированные поля.
- Рейтинг 0–100 считает backend по подтверждённой карточке. Веса: контекст/потребность 20, данные 20, результат 15, критерии успеха 15, ограничения 10, пользователи 10, связь с бизнесом 10.
- Уровни: 0–39 `needs_clarification`, 40–69 `workable`, 70–89 `ready`, 90–100 `priority`. Низкий рейтинг не запрещает публикацию и отклики.
- Каталог сортируется по рейтингу; можно фильтровать по теме и уровню. Бизнес вручную выбирает или отклоняет каждый отклик. Несколько выбранных команд допустимы.
- `revision` не позволяет устаревшей форме перезаписать новую правку. Каталог видит только подтверждённую версию карточки.

## Проверка

```powershell
cd server
npm.cmd test
```

Тест проходит путь через настоящий HTTP API и временную SQLite: публикация с баллом 0, шаблонные AI-вопросы, рост до 100 после подтверждения, каталог, две заявки, ручной выбор обеих команд, контроль доступа и повтор заявки. Живой OpenAI отдельно не протестирован, поскольку ключ команды не используется при тестах.

`node:sqlite` в установленной версии Node предупреждает об экспериментальном API. Для локального пятчасового MVP используется проверенная версия Node; для долгоживущего развёртывания БД и аутентификацию следует пересмотреть. Демо-профили намеренно не являются полноценной регистрацией.
