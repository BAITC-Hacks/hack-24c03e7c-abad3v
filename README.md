# AI Sana · Frontend MVP

React + Vite + TypeScript интерфейс для двух демо-ролей: бизнеса и студенческой команды. Сейчас приложение работает на локальных fixtures через mock API; клиент уже описан отдельным слоем и повторяет контракт из `src/api.ts`.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который напечатает Vite. В верхней панели можно переключать демо-профили бизнеса и студенческих команд.

## Подключение backend

Создайте `.env.local` рядом с `package.json`:

```env
VITE_API_MODE=api
VITE_API_BASE=/api
VITE_API_TARGET=http://localhost:3000
```

`VITE_API_TARGET` должен указывать на локальный адрес backend. В dev-режиме Vite проксирует `/api`; в production frontend и API должны быть доступны с одного origin, как описано в контракте. API-клиент отправляет cookie через `credentials: 'include'`.

Для локального интерфейса без backend оставьте `VITE_API_MODE=mock` (значение по умолчанию). Mock-режим реализует тот же поток: выбор демо-профиля, черновик и карточка, AI-вопросы/шаблонный fallback, подтверждение, рейтинг, публикация, каталог, отклики и решения по каждому отклику.

## Структура

- `src/types.ts` — TypeScript-модели контракта.
- `src/api.ts` — единый клиент; переключается между `/api` и mock-реализацией.
- `src/mockApi.ts` — локальный демонстрационный API и синтетические данные.
- `src/fixtures.ts` — 5 черновиков, опубликованные карточки, 5 профилей команд и 5 откликов.
- `src/App.tsx`, `src/styles.css` — экраны и визуальная система.
